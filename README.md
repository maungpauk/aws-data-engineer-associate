The AWS Certified Data Engineer - Associate Exam Prep Specialization on Coursera offers a four-course curriculum designed for the DEA-C01 exam, focusing on implementing data pipelines and optimizing storage using services like AWS Glue and Redshift. It covers critical skills for scaling data architectures, securing data, and monitoring operational performance, according to the Coursera course materials. 

This repository contains study notes, hands-on lab code, and exam prep resources for the **AWS Certified Data Engineer – Associate** certification, based on the 4-course Coursera specialization.

## 📚 Specialization Courses

- *Course 1*: [**Data Engineering Foundations on AWS**](/01-data-engineering-foundations/README.md)
- *Course 2*: [**AWS Databases & Compute for Data Engineers**](/02-databases-and-compute/README.md)
- *Course 3*: [**Real-Time Data Pipelines & Analytics on AWS**](/03-real-time-pipelines/README.md)
- *Course 4:* [**AWS Security, Logging & DevOps for Data Engineers**](/04-security-logging-devops/README.md)

## 🛠️ Key Technologies Covered

This specialization covers foundational data engineering concepts, including data modeling and SQL, alongside AWS storage and compute services like S3 and EC2. It also focuses on architecting scalable analytics pipelines with Apache Spark and Redshift, while ensuring proficiency in AWS networking, security, and cost control tools.

* **Storage & Databases:** S3, DynamoDB, RDS, Redshift
* **Compute:** Lambda, EC2, ECS, EKS
* **Data Integration:** Glue, Kinesis, Apache Spark, Airflow
* **DevOps:** CloudFormation, IAM, CloudWatch
